---

## 2. Working Agreements & Workflow
* **Protected Branch Policy**: Work is never committed directly to `main`. Features are developed on separate branches and merged into `main` via Pull Requests reviewed by at least one other member.
* **Issue Board & Ownership**: Every task is tracked as an Issue on the GitHub Projects board, and every issue must have an explicit owner.
* **Individual Accountability**: Each member commits meaningful work weekly from their own GitHub account as evidence for oral defences and peer evaluation.
* **AI Tool Transparency**: Any usage of AI tools for drafting or exploration is explicitly declared in `AI_USE.md`.

---

## 3. Communication & Meetings
* **Primary Communication Channel**: WhatsApp / Discord
* **Regular Syncs**: Weekly check-ins to review Sprint Notes and prepare for bi-weekly oral laboratory defences.
* **Conflict Resolution**: Unresolved technical or schedule conflicts are escalated to the Scrum Lead first, then reviewed during team syncs.
